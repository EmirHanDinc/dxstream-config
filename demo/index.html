DXStream demo content

DXStream is a player for IPTV services and playlists that users already have. It does not provide any channels or content. The in-app demo uses only the freely licensed works below, re-encoded to 720p HLS without other changes (letterboxed to 16:9), plus Apple's public HLS example streams. Program guide entries are illustrative.
